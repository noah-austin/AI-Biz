# Sales kit

Everything Sanford Operations uses to find and win the first clients.

| File | Use it for |
|---|---|
| `one-pager.md` | The pitch, for the website, a PDF leave-behind, or pasting into an email. |
| `outreach.md` | LinkedIn and email messages, referral-partner asks, follow-ups, post ideas. |
| `discovery-call.md` | The script for the first 15–20 conversations, and what to log afterwards. |
| Pitch deck | The 9-slide deck for second calls: https://claude.ai/artifact/RDNWEZv4HUpEgjdu5UfxfX (private; share it or download it as PowerPoint/PDF). Fill in the company name and date on slides 1 and 9. Speaker notes on every slide. |
| `linkedin.md` | Profile, company page and the first month of posts. Copy-paste version with images: https://claude.ai/artifact/PpNdbk8WpSzgkZZ9ayQG3q. Images in `website/brand/linkedin/`. |
| `targets.md` | Who to contact, where to find them, and the weekly routine for 20 hours a week. |

**The rule for confidentiality:** the first company is never named or described on the website or in posts. In conversation, never use its figures, customers or details beyond "a multi-branch commercial contractor".
